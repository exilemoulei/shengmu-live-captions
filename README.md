# 声幕 - 实时字幕翻译

捕获当前 Chrome 标签页的英文音频，使用本地 faster-whisper 实时识别，并通过 Index-Translate-9B 翻译成中文。字幕显示在视频页面浮层中，完整记录保存在扩展本地 IndexedDB 中。

## 已实现

- 仅采集当前标签页，不采集其他标签页或系统全局音频。
- 英文 ASR + 中文翻译，支持中英双语、双行译文（上句+当前句）、仅中文、仅英文四种显示模式；双语时原文按译文 60% 的字号显示。
- 翻译引擎可选 DeepSeek（默认）、OpenAI、任意 OpenAI 兼容 API 或本地 WhisperLiveKit 服务。
- 页面浮层支持拖动、字号调整、显示开关和暂停后保留；指针停在浮层上向上滚动滚轮可回看近期字幕，滚回最新一句后历史自动收起，且不会带动网页自身滚动。
- 字幕与历史窗口支持场次列表、搜索、续看、复制文本和 SRT 导出；直播时按行增量渲染，新字幕不会重刷整页。
- WebSocket 断线自动重连，重连后的时间码继续累加，不会回到 `00:00`。
- 页面刷新后自动重新注入浮层；标签页跳转后继续采集并同步标题、URL。
- 标签页关闭时只执行一次收尾，保留结束原因并保存最终字幕。
- 历史字幕写入串行化，失败批次会保留并自动重试，避免旧写入覆盖新译文。
- 停止时检查缺译字幕；正常停止但存在缺译时标记为 `incomplete`，不再静默当作完整结果。
- 所有识别、翻译和历史数据都在本机处理。

## 快速启动

本地模型、虚拟环境和 Chrome 需要已经安装；当前工作区的 `.research` 已包含这些依赖。

> 新安装默认使用 DeepSeek API。没有 API Key 时，先在扩展控制面板的“翻译引擎”里切换到“本地服务端”，或按下面的“翻译引擎”一节填写 Key。

```powershell
Set-Location -LiteralPath '<项目目录>'
.\scripts\Start-Services.ps1
.\scripts\Start-DevBrowser.ps1 -Url 'https://www.youtube.com/'
```

`Start-DevBrowser.ps1` 使用项目专用 Chrome 配置目录 `chrome-profile`，与日常 Chrome 配置隔离。首次启动可自行登录需要账号的站点。

### 翻译引擎

新安装默认使用 DeepSeek API 翻译。打开扩展控制面板，在“翻译引擎”中填入 DeepSeek API Key 后即可开始；Key 只保存在本机扩展存储中，不会同步，也不会发送给网页内容脚本。切换到其他服务商时，各服务商的 Key 会分别保存。Key 以明文形式存放在扩展本地存储中，依赖 Windows 账户与 Chrome 配置目录的访问控制；共用电脑上建议使用临时 Key 或本地服务端。

使用 API 翻译时，推荐让本地服务只做 ASR，避免重复加载 9B 翻译模型并占用显存：

```powershell
.\scripts\Start-Services.ps1 -AsrOnly
```

从 0.3.x 升级的旧配置会保持“本地服务端”模式，不会因为缺少 API Key 而中断；需要 DeepSeek 时在“翻译引擎”中切换为“API 翻译”并填写 Key。面板里的“测试翻译 API”会发送一句测试文本验证地址、模型和 Key。为防止把旧 Key 发到新地址，修改 API 地址后需要重新填写该服务商的 Key。

本地服务端模式仍然使用 `Index-Translate-9B`，适合离线或不想产生 API 费用的场景。

在目标视频页按 `Ctrl+Shift+Y` 打开声幕控制面板，点击“开始实时翻译”。按 `Ctrl+Shift+U` 打开字幕与历史窗口。

默认使用实时分段翻译，以优先满足 2-3 秒字幕延迟。若更在意减少译文回退闪烁，可以改用整句完成后再翻译的模式，但中文会明显更晚出现：

```powershell
.\scripts\Start-Services.ps1 -TranslateOnComplete
```

停止服务：

```powershell
.\scripts\Stop-Services.ps1
```

## 安装到日常 Chrome

如果不想使用项目专用 Chrome：

1. 打开 `chrome://extensions`。
2. 开启右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择项目目录下的 `extension` 文件夹。

更新扩展文件后，在 `chrome://extensions` 中点击声幕卡片上的“重新加载”。

## 使用限制

- 标签页内已经混合的声音无法单独排除，例如视频中播放的广告会一并转写和翻译。
- DRM 受保护内容是否允许 `tabCapture` 取决于浏览器和站点。
- 首次启动需要加载 Whisper 和翻译模型，通常明显慢于后续启动。
- 字幕延迟主要来自语音停顿、ASR、翻译和网络服务；本地链路当前实测通常为 1-3 秒，外部 API 还取决于网络和服务商响应速度。
- API 翻译按 token 计费；开启“半句预翻译”会更早显示中文，但请求次数和费用更高。
- 原生 `<video>` 元素自身进入全屏时，网页浮层可能不可见；可改用“声幕 - 字幕与历史”窗口查看。
- `deliveredRatio` 表示捕获到的音频时长与墙钟时长之比，用于判断采集是否持续，不等于 WebSocket 到 ASR 的成功投递率。
- **行为说明（0.4.3 起）**：ASR 偶尔会把很长一段语音切成一句（实测某 2 分钟 PoE 切片被切成 1 句、时长 120.06 秒）。浮层正文现在有行数上限：译文最多 3 行、原文最多 2 行、上一句最多 2 行，超出部分从顶部裁掉并做渐隐，只保留最新的几行，字幕框不会再铺满屏幕；浮层历史面板里每行同样限高（译文 2 行 + 省略号，原文 1 行省略）。完整原文与译文仍保存在历史窗口里。拖动过的浮层在内容变高后会自动拉回视口内。
- **行为说明**：静音或噪声画面下 ASR 仍可能吐出「7.8.」这类没有任何字母的碎片，扩展在归一化阶段按形态丢弃：只有标点/符号的行（如 `...`、`♪`）无条件丢弃；小数（`7.8.`）或时间码（`00:12`）形态的行，只有在该行时长 ≤ 1.5 秒时才丢弃（超过则视为真实口播保留）。普通整数（`42`、`1,024`、`2024`）一律保留；时间码缺失或无效（算不出时长）时也保留。丢弃的行不会显示、入库或送去翻译。
- **行为说明**：浮层向上滚轮进入历史回看后，面板锁定当时的行集合与顺序（条目快照），新到达的字幕不会插入，以免阅读位置跳动；已显示行晚到的译文会原地刷新，日志裁剪也不会让已显示的行消失。收起后回到实时，最新字幕照常进入历史。

## 开发验证

```powershell
npm test
```

单元测试覆盖重连时间码、跨 epoch 合并、SRT 时间轴、缺译识别，历史写入失败重试、并发写入和旧写入覆盖保护，记录页增量渲染的追加/滑动/重建判定，以及浮层历史日志的增量合并、晚到译文原地刷新与上限裁剪。扩展脚本可用以下命令做语法检查：

```powershell
Get-ChildItem -LiteralPath .\extension -Filter *.js |
    ForEach-Object { node --check $_.FullName }
```

v0.3.2 使用本地 TARGET 音频完成了一次 60 秒 Chrome 端到端验证：21 条历史字幕、最终缺译 0、场次状态 `stopped`、最长字幕 5.12 秒、音频捕获比中位数 `0.99968`；字幕窗口和页面浮层均已实际截图检查。此前的 YouTube 冒烟轮次被广告内容污染，不作为最终内容验收。

v0.4.0 的翻译 API 客户端由 `tests/translation-api.test.js` 使用本地 OpenAI 兼容 mock 服务覆盖：请求构造、DeepSeek thinking 关闭与 400 重试、鉴权/余额/限流/超时错误、JSON 解析、用量统计。2026-10-27 使用 0.5 发布会的 2 分钟切片做了一次真实 DeepSeek 端到端验证：Chrome + WhisperLiveKit ASR-only + DeepSeek API，31 条字幕、最终缺译 0、无 fallback、捕获比中位 `0.999976`、99 次请求 / 23,700 prompt tokens + 929 completion tokens、GPU 峰值 6,479 MiB；浮层和历史窗口截图见 `paseo/evidence/`。全量发布会因 token 成本不跑，长时稳定性和本地服务端回归留待需要时再验。

v0.4.3 修掉三个已知问题：超长 ASR 句会把浮层铺满屏幕、记录页场次列表长标题出横向滚动条、静音时的极短碎片行。验证：`npm test` 53 项全过；无服务 CDP 冒烟 `.research/ui-smoke-043.py` 8 项全过（正常单行不溢出、超长句译文限 3 行/原文限 2 行且顶部渐隐、字幕框高度 < 视口 45%、浮层历史行译文 2 行原文 1 行、短句回来时渐隐清除、拖动过的浮层被长句顶高后自动拉回视口、520px 高窗口 + 64px 字号下整块浮层仍在视口内）；0.4.2 冒烟 `.research/ui-smoke-042.py` 12 项回归全过；真实 WhisperLiveKit（`-AsrOnly`）对 2 分钟 PoE 切片的 134 条唯一转写过噪声规则，误杀 0。截图见 `paseo/evidence/v043-*.png`，细节见 `paseo/07-ui-fixes-0.4.3.md`。

v0.4.2 的评审问题修复用无服务的 CDP 冒烟脚本验证（专用 Chrome 9223 + 未打包扩展，向内容脚本注入伪造 `caption-state`）：12 项全部通过——历史面板 12 条、晚到译文原地刷新、新行不顶动阅读位置、滚回实时不带动网页、关闭后滚轮恢复滚动网页、重新注入后仍只有一个浮层且一格滚轮只走一行、拖拽（含面板打开时）与窗口缩放后命中区域跟随、历史日志封顶 60 条、回看期间新增 40 行后冻结行不消失。截图见 `paseo/evidence/v042-overlay-history-open.png` 与 `v042-overlay-history-closed.png`；细节见 `paseo/06-review-fixes-0.4.2.md`。真实 ASR/翻译链路的 240 秒采集回归本轮未重跑。
